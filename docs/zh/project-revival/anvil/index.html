从参考造型到装配

我为 ARC Raiders 中的 Anvil 等比例复刻开发了初版 Fusion 模型和零件架构。挑战在于保留原造型的辨识度，同时将它拆分为可独立打印、可继续开发的装配结构。

ARC Raiders 提供外观参考。零件建模和制作开发是我的个人项目。

明确各个零件在装配体中的位置

初版装配体包含十一件 CAD 零件，包括外部枪管护罩、前准星、握把面板、内腔和中心轴。装配图和爆炸图在实体配合检查前展示了零件之间的布置关系。

首次等比例打印

首版在中国进行了等比例打印，目前仍存放在那里。本页图像记录 CAD 设计及其演变，未展示实体打印件。

项目仍在开发，内部结构有待完成并测试。首次打印有了实体版本，配合、运动、装配、耐久性和声音表现仍需分别检验。

开发内腔结构

内腔、中心轴和支撑布局是一项原型方案。打印件的配合与运动是否顺畅仍待评估。

后续镂空方案

后续 CAD 研究探索了装饰鼓轮的镂空方式，保留外壳、中心套筒及连接筋板。这项研究与发声板独立，目前处于 CAD 原型阶段。

后续鼓轮和声学开发使用了 Codex 和 Fusion 辅助。目前图像用于设计讨论，打印件减重幅度、声音表现和实体效果仍待验证。

接下来的工作

检查打印零件的配合与装配，评估内腔机构的运动，并继续制作声音模块原型。长期目标是把一个由参考造型出发的复杂项目整理成清晰易懂的制作过程。
