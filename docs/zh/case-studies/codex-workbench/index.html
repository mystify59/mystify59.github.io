项目目标进度工作流程来源证据当前状态

让工作进展一目了然

我希望有一个工作台，能看清编程、研究和设计任务之间的联系、智能体正在做什么，以及哪些结果需要审查。我主导产品和工作流程设计，并使用 Codex 开发了这个原型。

目前已实现一个可在本地运行的原型，依托本机安装的 Codex 运行环境，提供任务关系图、实时活动记录和可持久化的项目状态。

关联任务、跟踪进展、审查结果

  1. 01

    定义任务

    选择项目文件夹、撰写任务说明并选取相关资料。

  2. 02

    关联相关工作

    用箭头标示前置依赖。前序任务的结果通过验收后，依赖它的任务才能继续。

  3. 03

    跟踪执行动态

    查看当前操作、带时间戳的事件、对话和检查点进度。

  4. 04

    审查并验收

    检查输出结果并核验检查点。智能体报告完成和用户验收分别记录。

查阅提供给模型的上下文

每项任务可选择符合条件的文件和已保存的研究摘录。SQLite FTS5 词项检索用于匹配相关段落；来源面板展示原文、行号范围、版本和交付状态。

每次运行都会重新检查文件，早期的证据快照也可以查阅。这些记录能说明工作台向 Codex 提供了哪些段落，模型实际采用了哪些内容仍需另行验证。

分离界面、任务状态和执行层

Electron / Codex App Server提供桌面窗口，并连接本机安装的执行环境。
