I wanted a workspace that shows how coding, research and design tasks connect, what an agent is doing, and which results need review. I directed the product and workflow design and developed the prototype with Codex.

The result is a working local prototype around the installed Codex runtime, with a task graph, live activity and persistent project state.

Make the supplied context inspectable.

Each task selects eligible files and saved research excerpts. SQLite FTS5 lexical retrieval finds matching passages; the Sources panel exposes their exact text, line ranges, revisions and delivery status.

Files are checked again for each run, and earlier evidence snapshots remain available. This records what Workbench supplied to Codex; it does not prove that the model relied on every passage.
